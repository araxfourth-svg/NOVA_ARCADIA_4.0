# La Ciudad que Dormía — Nova Arcadia 2087

## Publicación en GitHub Pages
1. Creá un repositorio público nuevo.
2. Descomprimí el ZIP y subí TODOS los archivos y la carpeta `imagenes` (sin carpeta contenedora extra).
3. Configurá Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Esperá la publicación y abrí la URL que informa GitHub.

## Juego
- 22 escenas narrativas con decisiones verificadas.
- Cada botón abre su escena y desplaza automáticamente la pantalla.
- Regresar, reiniciar, narración, sonido y pantalla completa.
- VERA responde en modo demostración. Para conectarla con Gemini, editá únicamente `config.js` y agregá la URL de tu Worker **después de verificar que funciona**. Nunca subas claves privadas a GitHub.

## Calidad de imágenes
- 22 archivos WebP de 1920×1080. La portada tiene arte nuevo de alta resolución.
- Las otras 21 escenas son versiones reescaladas de ilustraciones anteriores, por lo que **1920×1080 no equivale a detalle nativo Full HD**. Podés reemplazarlas progresivamente por renders nativos, conservando sus nombres.
